# 🔗 Como Gerar Seu Link Direto (2 minutos)

## Forma Mais Rápida - Vercel (Grátis)

### 1️⃣ Acesse e Conecte GitHub
- Vá em: https://vercel.com/new
- Clique em "Continue with GitHub"
- Faça login com sua conta GitHub

### 2️⃣ Importe Este Repositório
- Procure por: `Dharman-Claude-Code`
- Clique em "Import"

### 3️⃣ Deploy Automático
- Clique em "Deploy" (não precisa mudar nada)
- Aguarde 1-2 minutos

### 4️⃣ Seu Link Estará Pronto!
```
https://dharman-claude-code-SEU-NOME.vercel.app
```

**Pronto! Abra no celular ou navegador! 🎉**

## Alternativa - Netlify (Também Grátis)

### 1️⃣ Acesse
https://app.netlify.com/start

### 2️⃣ Conecte GitHub
- Clique em "GitHub"
- Selecione o repositório `Dharman-Claude-Code`

### 3️⃣ Configure Build
- **Build command:** `npx expo export --platform web`
- **Publish directory:** `dist`

### 4️⃣ Deploy
- Clique em "Deploy site"
- Seu link: `https://SEU-SITE.netlify.app`
